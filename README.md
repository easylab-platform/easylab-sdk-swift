# easylab-sdk-swift

Typed EasyLab client SDK for Swift over Connect (easylab.v1 + agent.v1 via
the easylab gateway). Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).

```swift
import EasyLabSDK

let client = EasyLabClient(baseUrl: "https://easylab.example.com", token: "...")
let repos = try await client.lab.listRepos(request: .init())
```

> Note: connect-swift supports Apple platforms only (iOS/macOS/tvOS/watchOS),
> so this SDK must be built with `swift build` on a macOS machine.

## Consumed as a Git dependency

```swift
// Package.swift
.package(url: "https://github.com/easylab-platform/easylab-sdk-swift.git", from: "0.1.0")
```

## Build

```bash
swift build
```
