# easylab-sdk-swift

EasyLab typed client SDK for Swift over Connect — **buf-generated code only**
(easylab.v1 + agent.v1 + worker.v1), public visibility. No hand-written
transport, auth, or wrapper: the caller builds its own `ProtocolClient` and
passes it to the generated service clients.

```swift
import EasyLabSDK
import Connect

let protocolClient = ProtocolClient(
    httpClient: URLSessionHTTPClient(),
    config: ProtocolClientConfig(host: "https://easylab.example.com", networkProtocol: .connect)
)
let lab = Easylab_V1_LabServiceClient(client: protocolClient)
let repos = await lab.listRepos(request: .init())
```

Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).

> Note: connect-swift supports Apple platforms only (iOS/macOS/tvOS/watchOS),
> so this SDK must be built with `swift build` on a macOS machine.

## Consumed as a Git dependency

```swift
// Package.swift
.package(url: "https://github.com/easylab-platform/easylab-sdk-swift.git", from: "0.3.0")
```

## Build

```bash
swift build
```
